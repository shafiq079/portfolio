Project previews and available live links are on the portfolio site.

## Built with

React, TypeScript, Vite, Tailwind CSS, and shadcn/ui components.

## Run locally

Install Node.js and npm, then run:

```sh
git clone https://github.com/shafiq079/portfolio.git
cd portfolio
npm ci
npm run dev
```

Open the local address printed by Vite. Use `npm run build` to create a production build in `dist/`.
